FAQ

Questions, answered

Is Neptune really free?

Yes — completely. There's no key system, no trial, no premium tier. Every feature is available to everyone, and we have no plans to ever charge for it. Hosting is on GitHub, source builds are reproducible, and the only thing you'll ever pay is your own attention.

What happens when Vortex updates?

Neptune's adapter re-resolves its internal offsets every time it launches, so a Vortex patch normally doesn't break anything. On the rare occasion a major update does cause friction, we ship a fix fast — and the rest of the time you don't even notice an update happened.

Is it safe? Could there be malware?

Every release is built straight from the public repo and published to GitHub Releases, so there's no middleman bundling anything extra. No miners, no telemetry, no droppers. If you're ever paranoid, you can diff the binary against a build you compile yourself.

Will I get detected or banned?

Neptune's stealth layer is continuously tuned to avoid Vortex's anti-cheat, and we've kept a clean track record so far. That said, no executor can ever promise zero risk — use it on accounts you're willing to lose, and follow the safe-use guide in the repo.

Which platforms are supported?

Windows 10/11 (64-bit) as a native .exe, and most modern 64-bit Linux distributions as a standalone binary with no extension. Just mark it executable with chmod +x Neptune and run it.

Where do I report bugs or request features?

Open an issue on the GitHub repository. Bug reports with reproduction steps get prioritised, and good feature requests are very welcome.
